# Домашнее задание 2 — Поиск регуляторных мотивов

## Описание алгоритма

В работе реализован алгоритм Гиббса (Gibbs Sampler) для поиска мотивов в наборе последовательностей ДНК.

Реализация включает следующие этапы:
- Случайный выбор начальных мотивов из каждой последовательности ДНК.
- Построение профиля нуклеотидов с использованием псевдосчётчиков.
- Вероятностный выбор k-мера на основе вероятностей, заданных профилем.
- Многократный запуск алгоритма для повышения вероятности нахождения хорошего решения.
- Сохранение лучшего набора мотивов и оценок всех запусков.

## Эксперимент

В качестве входных данных использован тестовый набор из задачи [Rosalind BA2G — Implement GibbsSampler](https://rosalind.info/problems/ba2g/).

Параметры эксперимента:

- `k = 8` — длина искомого мотива;
- `t = 5` — количество последовательностей ДНК;
- `n_iterations = 200` — количество итераций в одном запуске;
- `n_restarts = 30` — количество повторных запусков;
- `seed = 42` — начальное значение генератора случайных чисел для воспроизводимости результатов.

## Ответы на теоретические вопросы

### 1. Чем вероятностный выбор в Gibbs sampler отличается от Profile-most probable k-mer по профилю?

При выборе наиболее вероятного k-мера по профилю алгоритм детерминированно выбирает k-мер с максимальной вероятностью. При вероятностном выборе в алгоритме Гиббса каждый k-мер может быть выбран с вероятностью, пропорциональной его вероятности по профилю.

Таким образом, алгоритм Гиббса может выбирать не только наиболее вероятный k-мер, но и другие варианты. Это позволяет исследовать различные комбинации мотивов и снижает вероятность застревания в локальном оптимуме.

### 2. Почему при построении профиля удаляется текущий мотив выбранной последовательности?

На каждой итерации выбирается одна последовательность ДНК, и её текущий мотив исключается из набора мотивов, используемых для построения профиля.

Это необходимо, чтобы вероятность нового мотива определялась остальными последовательностями, а не самим заменяемым мотивом. Иначе текущий мотив влиял бы на распределение вероятностей собственного обновления, что могло бы усиливать уже сделанный выбор и ухудшать исследование других вариантов.
